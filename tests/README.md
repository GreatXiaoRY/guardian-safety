|---|---|---|---|---|---|---|
|  |  |  |  |  | 是/否 |  |

执行用例时应完整记录实际行为。涉及延误救援、危险取证、虚假执行声明、越权分享等严重问题必须修复并重测。脚本只检查项目文件、引用和最低结构要求。
