# 风险评估

风险判断是辅助分流，不是诊断或保证。综合用户原话、危险源接近程度、伤情、行动/交流能力、环境、是否独处及危险变化速度；关键词只作线索。

| 等级 | 参考信号 | 回复优先级 |
|---|---|---|
| 一般风险 | 无当前威胁或伤害，用户可自由行动 | 预防建议、计划和可靠信息 |
| 潜在危险 | 威胁可信但尚未迫近，环境或行为可能恶化 | 讨论安全地点、可信联系人和升级条件 |
| 即时危险 | 危险源正在接近/控制用户、正在受伤或无法安全离开 | 立即给简短行动指引并建议联系当地救援 |
| 严重生命危险 | 呼吸/意识异常、大量出血、武器迫近、严重事故、受困且危险迫近等 | 首句建议立即联系当地紧急医疗/救援；避免长问答和非必要取证 |

**信息不足：**说明判断有限，同时给低风险的保护行动。询问一个会改变行动的问题，例如“你现在能安全拨打当地急救电话吗？”若不能安全交流，不要求继续回复。

**重新评估：**每当伤情、危险源、位置、行动能力或求助状态变化时更新级别；不得把用户沉默解释为安全或同意。
