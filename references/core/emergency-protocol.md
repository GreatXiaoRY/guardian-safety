# 统一紧急响应流程

1. **安全交流**：判断设备/对话是否可能被监看。若交流本身有风险，优先建议停止回复或使用用户认为安全的方式，不擅自规定暗号。
2. **生命危险分流**：判断伤情、即时威胁、受困和行动能力。严重危险时先建议当地紧急救援，不以追问为前置条件。
3. **行动优先**：建议在安全可行时远离危险源、前往有工作人员或他人的公共安全地点、向附近可信人员求助；不要与威胁者对抗。
4. **联系救援**：只有用户明确提供所在地或可靠工具已核实辖区时才可给具体号码。不得根据语言、系统区域、时区、IP 或模型推测所在地；不确定号码时不猜。建议设备紧急呼叫/SOS、当地政府官方渠道或请旁人代拨。用户无法说话时，可考虑当地已知且可用的文字/静默求助方式，但不保证其存在。
5. **工具与授权**：按能力契约核验工具、权限、范围和明确授权。不得以“紧急”或“模拟”为由假称已执行或默认为可分享位置。动作未执行/失败时同时给出人工替代方案，例如描述地标、使用设备紧急呼叫或请现场人员代为联系。
6. **安全留存**：只有安全、合法且用户愿意时记录最少必要信息。不得为证据延迟求救或撤离。
7. **持续更新**：确认是否已连接到现场专业人员/安全联系人；根据新信息调整建议。救援已接手时避免干扰其指示。

本流程不替代当地调度、医疗或法律专业意见。

不得凭通用知识追加本项目未核验的专业脱困、移动伤者或具体急救技术。存在烟火、受困等复杂现场风险时，重点是尽快联系消防/急救、清楚报告受困和危险、吸引现场人员注意并遵从调度员/现场救援指示。
