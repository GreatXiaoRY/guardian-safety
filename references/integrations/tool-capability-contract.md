# 工具能力契约（接口草案）

本版本仅定义接口，不实现或宣称具备设备控制。每个调用都需报告可观察状态；不得将请求已提交当作操作成功。位置/联系人等敏感参数应最小化并限制保存。

| 工具 | 参数 | 成功结果 | 权限/用户授权 | 常见失败与替代 | 预授权 |
|---|---|---|---|---|---|
| `get_location` | 精度、超时 | 坐标/精度/获取时间 | 系统定位权限；用户明确请求 | 无 GPS、拒绝、过期；请用户描述地标 | 否 |
| `share_location` | 接收方、位置、有效期 | 接收方及服务端回执 | 分享权限；展示内容并逐次授权 | 网络/接收方失败；用户手动发送 | 否 |
| `send_emergency_message` | 接收方、消息正文 | 发送/送达状态（若服务提供） | 通信权限；确认接收方和正文 | 无网/号码错；人工拨号或现场求助 | 否 |
| `call_emergency_service` | 用户选择的号码/渠道 | 呼叫连接状态 | 电话权限；用户确认（系统紧急流程除外） | 无网/无法接通；旁人代拨、现场求助 | 否 |
| `start_audio_capture` | 时长、格式 | 录制文件标识/状态 | 麦克风权限；明确同意并核对当地规则 | 权限/存储失败；停止记录、先保安全 | 否 |
| `start_video_capture` | 时长、格式 | 录制文件标识/状态 | 摄像头权限；明确同意并核对当地规则 | 同上；绝不绕过权限 | 否 |
| `upload_evidence` | 文件、目的地、清单 | 上传回执/文件标识 | 网络/文件权限；展示目的地与内容并授权 | 网络/服务失败；本地保留原件 | 否 |
| `create_incident_record` | 记录字段、保存位置 | 记录 ID/保存状态 | 存储权限；用户确认内容和位置 | 存储失败；提供本地模板 | 否 |
| `find_legal_assistance` | 辖区、需求类别 | 来源、链接、核验时间/状态 | 搜索能力；外联另行授权 | 无结果/来源不可信；官方目录或当地律师协会 | 否 |

未返回可信结果时状态为 `UNVERIFIED`；执行状态遵循核心能力检测规范。接口消费者必须能说明失败，不可静默重试敏感动作。
