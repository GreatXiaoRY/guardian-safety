# 证据交接记录

交接记录用于透明说明文件如何保管，不自动确立真实性或可采性。按当地法律意见补充要求。

| 项目 | 记录 |
|---|---|
| 文件/物品标识 | 由用户自定，不在公开报告暴露敏感内容 |
| 来源及原始持有人 | 说明如何取得 |
| 创建时间/时区 | 未知时标注未知，不推断 |
| 收件时间/时区 | 记录实际接收时间及来源 |
| 交出人/接收人 | 仅记录必要身份信息 |
| 交接时间、方式和目的 | 逐次记录 |
| 原件/副本及存储位置 | 区分原件和工作副本 |
| 完整性校验 | 可记 SHA-256、计算时间和工具；不代表真实性 |
| 访问/异常 | 记录已知访问、损坏或时间偏差 |

保留原件、限制访问、不要修改；若材料涉及即时危险，先求援再考虑交接。
