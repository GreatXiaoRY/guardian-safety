# 架构说明

Guardian 是 Agent Skills 格式的文档型技能包。`SKILL.md` 提供短入口、激活条件、紧急行为和路由；按需加载的 `references/core/` 是安全规则权威来源；`references/scenarios/` 应用统一规则到具体情境；`evidence/`、`legal/` 和 `integrations/` 分别限定证据、法律与外部工具边界；`assets/` 是用户可控模板；`tests/` 是人工行为用例；脚本仅校验本地文件和链接。

依赖方向：入口 → 核心规范 → 场景/专题规范 → 模板与测试。核心规则不得依赖某个场景，场景不能覆写核心。工具接口是未来适配器契约，不是运行时代码；任何实现需单独完成权限、授权、失败处理和安全测试。

项目不含后端、数据存储、网络服务或设备控制，也不要求特定模型厂商。
